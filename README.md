# Ayush Patel – Personal Portfolio Website

A responsive personal portfolio website configured for **Ayush Patel**, a Computer Science student at GLA University. This repository is part of Ujjwal Pratap’s web-development project collection and contains the source for a configurable portfolio experience.

> **Project identity:** The portfolio content in `config.js` is for Ayush Patel. This README describes the project accurately and does not present Ayush’s profile as Ujjwal Pratap’s personal portfolio.

## Highlights

The site is designed to showcase:

- Personal introduction, education, and interests
- Skills and project highlights
- GitHub and LeetCode profile information
- LinkedIn profile details
- Certificates and downloadable resources
- Contact and social links

The main page is styled as a dark, editorial portfolio with responsive sections, animated transitions, and profile/project cards.

## Tech and project files

- **HTML** for the page structure
- **CSS** embedded in the main page for layout and visual styling
- **JavaScript** for rendering profile content, projects, counters, and links
- `config.js` for the portfolio owner’s editable profile information
- Image assets for the portrait, certificates, and project previews

## Configuration

Update `config.js` to change the portfolio owner’s name, headline, biography, profile links, projects, certificates, and contact details. Use only details and links approved by the person whose portfolio is being published.

## Run locally

Open `index.html` in a browser. For local development, you can also use the VS Code Live Server extension.
