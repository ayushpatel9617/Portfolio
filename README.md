# Ayush Patel – Personal Portfolio Website

A responsive personal portfolio website configured for **Ayush Patel**, a Computer Science student at GLA University. 

## Highlights

The site is designed to showcase:

- Personal introduction, education, and interests
- Skills and project highlights
- GitHub and LeetCode profile information
- LinkedIn profile details
- Certificates and downloadable resources
- Contact and social links

The main page is styled as a dark, editorial portfolio with responsive sections, animated transitions, and profile/project cards.

## Tech and project files

- **HTML** for the page structure
- **CSS** embedded in the main page for layout and visual styling
- **JavaScript** for rendering profile content, projects, counters, and links
- `config.js` for the portfolio owner’s editable profile information
- Image assets for the portrait, certificates, and project previews
